GitHub

  1. Apri Crea un token fine-grained su GitHub. Dagli un nome e scegli una scadenza.
  2. In Resource owner seleziona il proprietario del repository. In Repository access scegli Only select repositories e seleziona i repository da usare.
  3. In Repository permissions assegna i permessi che servono alle operazioni che vuoi usare.

GPT di OpenAI

  1. Accedi alla pagina delle chiavi API OpenAI, seleziona il progetto e scegli Create new secret key.
  2. Se limiti i permessi della chiave, abilita la lettura dei modelli e l’uso della Responses API per generare le proposte. Il progetto deve avere accesso al modello che scegli.
  3. Nell’app vai in Connessioni → Modelli AI, scegli OpenAI · GPT, incolla il valore in Chiave API e premi Verifica e collega.

Claude di Anthropic

  1. Accedi alle chiavi API della Claude Console e crea una chiave associata al workspace che vuoi usare.
  2. Nell’app vai in Connessioni → Modelli AI, scegli Anthropic · Claude, incolla il valore in Chiave API e premi Verifica e collega.
Documentazione Claude ↗

Gemini di Google

  1. Accedi alla pagina API keys di Google AI Studio. Crea una chiave Gemini nel progetto Google che vuoi usare.
  2. Nell’app vai in Connessioni → Modelli AI, scegli Google · Gemini, incolla il valore in Chiave API e premi Verifica e collega.

Dopo aver collegato uno o più provider, scegli il provider e il modello in Workspace. Le richieste sono soggette a quote e fatturazione del progetto API del provider.

Supabase

  1. Apri Access Tokens nel tuo account Supabase e genera un Personal Access Token per la Management API.
  2. Per un token con permessi granulari, concedi Projects (account-wide) in lettura per l’elenco dei progetti.
  3. Vai in Connessioni → Supabase, incollalo in Token Management API e premi Carica progetti.

Per questa schermata serve il token personale dell’account. Le chiavi anon e service_role sono credenziali del singolo progetto.

Vercel

  1. Apri Access Tokens di Vercel. Crea un token, scegli una scadenza e seleziona lo scope dell’account o del team che contiene i progetti.
  2. Vai in Connessioni → Vercel e incollalo in Token Vercel. Per un team puoi inserire anche il suo slug o il Team ID, che trovi nelle impostazioni del team.
  3. Premi Collega Vercel, seleziona il progetto e usa Carica deploy. Dall’elenco puoi vedere stato e ambiente, aprire il deploy o passare alla dashboard.

Prima modifica e build

  1. Apri un repository con GitHub e collega almeno un modello AI. In File, seleziona fino a otto file da usare come contesto.
  2. In Workspace descrivi la modifica e premi Genera proposta. Controlla il diff e usa Apri pull request per inviare i file selezionati su un branch dedicato.
  3. Per creare un’app Flutter, usa File → Prepara modello Flutter in un repository senza i file del modello. Integra la relativa PR nel branch predefinito, riapri quel branch in CosmoCoding e poi usa Build → Avvia build.
  4. Apri l’esecuzione su GitHub Actions e scarica il pacchetto della piattaforma dalla sezione Artifacts.

Errori di accesso

401 · Credenziale rifiutata
Ricopia il valore dal servizio e verifica la scadenza. Se non è più visibile, crea una nuova chiave.
403 · Permessi insufficienti
Verifica i permessi e il repository, progetto o team associato al token.
404 · Risorsa non accessibile
Controlla il nome del repository e del branch, poi verifica che il token abbia accesso.
429 · Limite API
Controlla quota, budget e limiti del provider prima di riprovare.

Incolla le credenziali solo nei campi di Connessioni. CosmoCoding le tiene in memoria per la sessione. Dopo aver chiuso o ricaricato il workspace, collegale di nuovo.
